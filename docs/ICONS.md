# Icons — Silver Suite

A procedural placeholder icon ships in `assets/icon/icon.png`. Replace
with a Nano-Banana-generated icon using the prompts below, then re-run
`flutter pub run flutter_launcher_icons`.

## Nano Banana prompts

### Prompt A — bold, calm, high-contrast (recommended)

```
A minimalist 1024x1024 app icon, square with 22% rounded corners, for a
senior-friendly utility app. Solid primary background in a confident
medium blue (#1864C0). Centered: a bold white circle that takes about
60% of the icon width, with a gentle diffused drop shadow under it.
Inside the white circle: a single, thick, rounded medical-style plus
sign in the same medium blue (#1864C0), slightly taller than wide.
Top-right corner: a small warm amber dot (#E08900) about 8% of the
icon width, like a warm sun. No text, no gradients, no noise. Flat,
friendly, confident. App Store aesthetic.
```

### Prompt B — alternative (more literal "phone" read)

```
A 1024x1024 app icon, medium-blue (#1864C0) rounded-corner square. In
the center, a white rounded card (like a large tile) at ~60% width.
Inside the card, a bold solid-blue handset/phone glyph, cleanly drawn,
not cute, slightly tilted 15 degrees. A small amber sun accent
(#E08900) in the top-right. No text. No gradients. Premium iOS
aesthetic with a touch of warmth to feel approachable for older users.
```

### Adaptive foreground prompt (Android)

```
Same circle-plus composition, 1024x1024, TRANSPARENT background, artwork
centered in the inner 66% safe zone. Do not place anything in the outer
17% on any edge.
```

## Save paths

- `assets/icon/icon.png` — main 1024×1024 (iOS + store uploads).
- `assets/icon/icon_fg.png` — adaptive foreground (transparent bg).
- `web/favicon.png` — auto-regenerated by the tool.

## Regenerate

```bash
flutter pub run flutter_launcher_icons
```

## Design rules that matter

- **Readable at 44×44.** The plus cross stays visible even at a watch
  or notification size. If you swap in a custom icon, test this first.
- **One dominant color.** Blue reads as "safe / utility" and matches
  the in-app primary, so the icon → launch screen → app shell feel
  like one design.
- **Accessible contrast.** White-on-blue and amber-on-blue both exceed
  WCAG AAA in the rendered output.
- **No alpha on iOS** (`remove_alpha_ios: true` is set).
